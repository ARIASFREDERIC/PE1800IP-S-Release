# Oracle Linux

Folder for build of PE1800IP-S  Oracle Linux Release

On each release :

- RELEASE_ORACLE_LINUX/VERSION/README.md : Date of build.
- RELEASE_ORACLE_LINUX/VERSION/build_status.txt : Build status.
- RELEASE_ORACLE_LINUX/VERSION/checksum.txt : Checksum of software.
- RELEASE_ORACLE_LINUX/VERSION/version.txt : Version of PE.
